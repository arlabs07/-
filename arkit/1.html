1. Quick Integration

Add the following script to your HTML file. It handles everything including styles.

<script src="https://arlabs07.netlify.app/arkit/1.js"></script>

2. Usage

ARKit automatically intercepts standard console methods and network errors.

// These will automatically trigger notifications
console.log('Hello World');
console.error('Something went wrong');

// Or use the manual API
window.arkit.notify('success', 'Operation Complete');

3. Features

  • Stacking: Notifications stack with a 3D depth effect.
  • Expandable: Click on truncated text to view the full message.
  • Auto-Dismiss: Notifications disappear after 5 seconds (pauses on hover).
  • Swipe to Dismiss: Touch-enabled swipe gestures for mobile users.
  • Hover Controls: Close buttons appear only when interacting.

Privacy Policy

Last Updated: January 7, 2026

At ARhub (arlabs07), we value transparency regarding how your data is handled when you use our ecosystem of tools, including PurplePDF, ardev, and the Arai AI assistant.

1. Data Collection & Analytics

We collect data to better understand how our tools are used and to improve the ecosystem.

  • Analytics: This website uses analytics services to track user behavior, traffic sources, and engagement metrics. This data allows us to optimize performance and user experience.
  • Usage Data: We may collect information about how you interact with our features, including page visits, duration, and feature usage.

2. Arai AI Assistant & Data Training

When using the Arai AI coding assistant and related AI features:

  • Code Usage: Any code snippets, text prompts, or context you submit to the Arai AI assistant may be stored and analyzed.
  • Model Training: We may use the code and data sent to Arai to train, fine-tune, and improve our machine learning models. By using these services, you explicitly consent to your inputs being used for these purposes.

3. Local Processing Tools

Certain tools, such as PurplePDF, are designed to prioritize local processing using Web Assembly (Wasm) where possible. However, usage metadata may still be collected as described in Section 1.

4. Third-Party Links

Our website may contain links to external sites (e.g., GitHub, CodePen, Blogger). We are not responsible for the privacy practices or content of these third-party sites.

5. Contact Us

If you have questions regarding this policy, please reach out via the channels listed on our Contact Page.

Frequently Asked Questions

What is ARhub?

ARhub is a comprehensive developer ecosystem created by arlabs07. It features a suite of tools including PurplePDF, the ardev library, and the Arai AI assistant, all designed to streamline the development workflow.

Is PurplePDF free to use?

Yes, PurplePDF is a free utility within the ARhub ecosystem. It allows users to merge, split, and compress PDF documents directly in the browser using Web Assembly technology for enhanced privacy.

How does Arai AI help developers?

Arai AI provides real-time syntax analysis, context-aware code suggestions, and automated performance audits. It is designed to act as an intelligent companion to help debug and optimize your code faster.

Can I use the live compiler on mobile?

Absolutely. The ARhub live compiler is fully responsive and optimized for mobile devices, allowing you to write and preview HTML, CSS, and JavaScript on the go.

How is my data used?

We value your privacy. We use analytics to improve services, and code sent to Arai AI may be used for model training to improve the assistant's accuracy. Please review our Privacy Policy for detailed information.
